# Pantograph Sim

3D-симулятор колебаний пантографа (Godot 4.2). Двухмассовая модель полоз + рама, переменная жёсткость контактной сети, зигзаг провода, порывы ветра, аэродинамическая подъёмная сила, отрыв полоза с искрением.

Управление: слайдеры слева сверху, свайп — вращение камеры, щипок/колесо — зум.

APK собирается GitHub Actions: вкладка Actions → последний запуск → Artifacts → pantograph-sim-apk.
