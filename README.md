# Pantograph Sim

3D-симулятор колебаний (шатания) пантографа на Godot 4.

- двухмассовая модель: полоз + рама, пружины и демпферы
- контактная сила, жёсткость и провис контактного провода, зигзаг, аэродинамический подъём
- искры при отрыве полоза от провода
- слайдеры скорости, ветра и масштаба колебаний, 3 камеры

## APK

Каждый push в main запускает GitHub Actions (Build APK). Готовый APK лежит во вкладке Releases и в Artifacts запуска.
